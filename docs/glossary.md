# Glossar: Deutsch → Englisch

Seit dem Umbau vom 04.11.2026 heißen Ordner, Dateien, Bezeichner, Kommentare und die Feldnamen der Spieldaten englisch. Deutsch bleiben Texte in Oberflächen, Namen und Beschreibungen in den Spieldaten, Commit-Nachrichten, `CLAUDE.md` und die Projekt-Docs.

Neuer Code nimmt die Wörter aus dieser Liste, damit überall dieselben Begriffe fallen.

**Inhalts-IDs** (z. B. `kampfpanzer`, `haus`, `opa_haus`) sind Daten und bleiben, wie sie sind. Bestanden sie nur aus Systembegriffen, wurden sie beim Umbau mit übersetzt (z. B. `ort_laden` → `place_shop`, Tag `metall` blieb).

## Abweichungen je Bereich

- `spiel/speicher.js` `werkzeuge/uebernimm.js` `spiel/splash.js` `spiel/editor.js` …: stand → drafts
- `engine/netz/` `werkzeuge/party/` `spiel/party/` `test/netz.test.js` …: platz → seat, protokoll → protocol, plaetze → seats, stand → sync
- `engine/tactics/` `spiel/tactics/` `werkzeuge/nt.js` `werkzeuge/werkstatt_test.mjs` …: ebene → overlay, ebenen → overlays, stufe → tier, stufen → tiers, unter → sub, nach → after, stand → state
